## Look (L2)
Background flat cream #F3EDE1. Ink #141312, 5 px outlines, flat fills + one shade, soft ground shadows. Accent red #D54E4C. Secondary butter yellow #F2D98B (highlighter swipe / fills).
Statement: Inter Tight 800, 110–170 px, left at x 90, max 2 lines, one word red or highlighter-swiped. Object labels: Inter 600 30–36 px UPPERCASE letter-spaced.
Every beat = one bold statement + one big illustrated example (object ≥ 420 px tall, filling roughly y 330–1150). Never a text-only beat. Uncluttered and polished.

## Zones (strict)
1080×1920. All graphics + graphic text inside y 180–1170, x 80–960 (x>960 clear for Reels icons). Gap y 1170–1250 empty.
Captions ONLY via assets/captions4.js in y 1250–1390 (dark pill, spoken word highlighted). Nothing below y 1420.

## Captions + audio
- `<script src="assets/gsap.min.js"></script><script src="assets/captions4.js"></script>`; inline assets/captions.json as CHUNKS and call
  `window.addCaptions4(tl, CHUNKS, {theme:"ink", lastEnd:D})`. Root element id="root". Do not edit captions4.js or captions.json text.
- Voiceover: assets/vo.wav (timings in captions.json are already real, from speech-to-text). DRIVE the beats from those times: each object/number
  should land within ~0.15 s of its spoken word. Render SILENT, then mux:
  `ffmpeg -y -i out.mp4 -i assets/vo.wav -filter_complex "[1:a]apad[a]" -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -t D final.mp4`
- No music.

## Motion (real motion graphics, not fades)
Words slide up from masks one by one; highlighter swipes draw left→right; objects pop with back.out overshoot; numbers roll (deterministic);
strike-throughs draw; coins drop with bounce; gentle camera push per beat; real transitions between beats (type pushes out up as next pushes in,
object morphs/slides into the next object). Keep motion readable — hold each finished state ≥ 0.6 s before transitioning.

## Hyperframes rules
- `<html data-resolution="portrait">`, `<div id="root" data-composition-id="main" data-start="0" data-duration="D" data-width="1080" data-height="1920">`.
- Each beat `<section class="clip scene" data-start=".." data-duration=".." data-track-index="N">`, unique track index per scene.
- One paused GSAP timeline: `const tl=gsap.timeline({paused:true}); ... window.__timelines=window.__timelines||{}; window.__timelines["main"]=tl;` end with `tl.to({},{duration:0.01},D-0.01);`
- Deterministic only: no Math.random (seeded/hardcoded), no Date, no CSS animations/transitions, no rAF, no external URLs. Fonts via @font-face from assets/.
- Intentional overlaps: data-layout-allow-overlap / data-layout-allow-occlusion.
- In project/: `export PATH=$NODE_BIN:$PATH`; `npx --yes hyperframes@0.9.72 lint` (fix errors) → `npx --yes hyperframes@0.9.72 check` (fix errors) → `npx --yes hyperframes@0.9.72 render --quality looks -o out.mp4` → mux to final.mp4.

  text-only, off-palette, overlapping the caption pill, or mistimed. Iterate at least once. ffprobe final.mp4: 1080x1920, has audio, duration D.

# Substack Notes

Short text posts on Substack (pallavkulhari.substack.com, the Quit 9to5 publication, @pallavkulhari). They extend the reach of a reel or card to Substack readers. Prompt: [prompts/substack-note.md](../prompts/substack-note.md).

## Rules (from the box, 16–20 Nov 2026)

- **Text only** (since 20 Nov 2026). No image, no video.
- **Scheduled at the matching social slot**, not posted instantly or back to back (since 18 Nov 2026). If the reel goes out at 2:00 PM IST, the Note is scheduled for 2:00 PM IST the same day.
- **Done in the browser.** There is no Substack channel in this workflow's Buffer; open Substack's Notes composer in the browser, write the Note and use its schedule option.
- **Approval:** like every non-blog item, a Note needs Pallav's explicit OK. Show it in its own review message alongside the reel's captions. Not every slot gets a Note (reel 003 had none); only schedule the ones he picks.

## How to write one

Usually adapted from the reel's caption:
1. Start from `THREADS.txt` (already compressed) or the first half of the Instagram caption.
2. Keep the hook line and the core explanation, in full sentences, Pallav's voice.
3. One concrete example or one practical step.
4. "Educational, not financial advice." if money numbers appear.
5. End with the waitlist CTA. The box has no separate written rule for the Note CTA. Substack has no "bio" link, so "Join the waitlist in bio" reads oddly there; propose "Join the waitlist at quit9to5.in." for a Note and let Pallav confirm the wording in his review. Once he picks one, use it consistently.

Length: short. Aim for the Threads length (under about 500 characters) unless Pallav asks for more.

## Log and follow-up

- Record the Note in the post log row of the matching item ("Substack text-only note scheduled separately").
- When it is live, send the link to the review bot.
- If a Note goes out at the wrong time, delete and reschedule it for the matching slot (this was done on 19 Nov 2026) with Pallav's OK.
